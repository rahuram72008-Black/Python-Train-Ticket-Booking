# Train Ticket Booking System

A simple train ticket booking application built using Python and Tkinter.

## Technologies Used
- Python
- Tkinter
- SQLite

## Features
- Passenger name entry
- From and To station selection
- Train selection
- Journey date
- Ticket booking
- SQLite database support

## Project Type
Mini Project
